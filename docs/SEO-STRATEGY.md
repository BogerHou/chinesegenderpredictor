# SEO 策略

核验日期：2026-10-08。定位：面向英语用户的 Chinese Gender Predictor 民俗娱乐工具。工程约束：静态站，esbuild + lunar，部署至 Vercel。

## 目标与依据

首页名称与主关键词统一为 **Chinese Gender Predictor**；Chinese Gender Calendar、Chinese Gender Chart、Chinese Birth Chart 作为同一搜索意图的自然表达，由首页一起承接，不另建同义词落地页。

竞品普遍已有计算器，部分已支持农历转换、预产期和完整图表。因此，产品重点是输入清楚、结果过程可检查、手机操作顺畅、说明可信，不宣称“唯一计算器”或“更准确预测性别”。详见 [竞品核验](COMPETITOR-ANALYSIS.md)。

原对话涉及的搜索量、流量、关键词难度、广告收益和排名预期均未独立验证，不作为本项目的已知数据或收益承诺。当前搜索观察用于判断意图，不能等同于完整 Google 排名或需求规模报告。

## 首发范围

采用 [站点结构](SITE-STRUCTURE.md) 中的 8 个路由：5 个工具／知识内容页，3 个信任与政策支持页。FAQ 放在相关页面，不单独铺设薄内容页；不按年龄、月份、男孩／女孩结果批量生成页面。

内容应解决四类任务：立即尝试；理解农历年龄和受孕月份；查阅 2027 年日期；判断准确性。文章长度以回答问题为准，不为固定字数重复内容。

## 内容与信任要求

- 表单和结果附近明确说明娱乐用途。结果是所选传统图表的猜测，不是医学判断。
- 说明生日、受孕日期与预产期的不同含义；估算的受孕日期标明估算，不制造精确感。
- 展示计算采用的农历年龄、农历月份、图表坐标；说明图表来源、版本与闰月处理约定。农历换算正确不代表预测具有科学效力。
- 民间来源故事写为传说，不将皇室墓葬、流传年数、所谓“原版”当成已证实历史。
- About 提供真实维护者／团队说明、方法与校正渠道。没有真实医学审核时，不添加医生身份或审核徽章。
- 不将“选月份提高生男／生女概率”作为工具收益或行动建议。

科学说明优先引用 [2010 年原始研究](https://pubmed.ncbi.nlm.nih.gov/20618730/)：研究分析 2,840,755 次瑞典单胎出生，结果不优于随机猜测。农历日期校验使用 [香港天文台公历农历对照资料](https://www.hko.gov.hk/en/gts/time/conversion1_text.htm)，不要用竞品结果作为唯一正确性基准。以上证据于 2026-10-08 核对。

## 技术与隐私

- 页面正文、标题和可访问表格随静态 HTML 提供；主功能渐进增强，说明内容不依赖执行 JavaScript。
- 每页一个明确 H1、独立 title／description、自引用 canonical；生产域名确定后统一站点地图、canonical 与社交分享 URL。
- sitemap 只列正式静态页面；结果、复制操作和动态参数不生成可索引 URL。日期只保存在本地交互状态，不放进链接参数。
- 图表不能只靠颜色表达；表单有标签、错误说明、键盘操作和结果播报；手机表格提供清晰的横向浏览方式。
- 结构化数据仅描述真实内容，可使用 WebSite、WebPage、BreadcrumbList；不伪造评分、医疗身份或审核，不承诺 FAQ 富结果。
- GSC、GA4、AdSense 留待用户账号配置。接入前核查真实数据流，再更新隐私文本；生日、受孕日期、预产期及预测结果不传入埋点。
- 若后续接入广告，预留广告位置，避免内容跳动；不把广告挡在工具前面。

## 前三个月的衡量方式

上线后建立有效索引、非品牌展示／点击、查询对应页面、工具成功完成率和输入错误率的基线。工具事件仅使用不含个人输入的事件名称／类别。先检查抓取、索引和使用障碍，再根据真实查询调整内容。

未有基线前不设虚构的访问量或收入增长目标；按 [实施路线](IMPLEMENTATION-ROADMAP.md) 完成基础验收，按 [内容日历](CONTENT-CALENDAR.md) 决定扩展。
