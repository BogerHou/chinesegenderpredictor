# 网站品质基准：Awwwards、Webby Awards、FWA

核对日期：2026-10-09。适用站点：chinesegenderpredictor.net。

用户要求以三个奖项的优秀作品为品质目标。这里将官方评审维度转化为可检查的项目标准；不是评委评分、获奖认证或获奖保证。当前任务是提升并验收网站，不包含付费报名。

## 官方评审依据

| 奖项 | 可核实的官方依据 | 对本项目的要求 |
| --- | --- | --- |
| Awwwards | 官方作品页公开 Design 40%、Usability 30%、Creativity 20%、Content 10%；开发评价另列性能、响应式、语义/SEO、标记与元数据、动画、无障碍。 | 原创的视觉叙事必须与计算器的易用性同时成立。不能只改首页截图；内容页、表单、结果、图表、打印材料都应完整。 |
| Webby Awards | 2026/2027 网站评审列内容、结构与导航、视觉设计、功能、交互、创新、整体体验。视觉标准强调适合受众与包容性；功能标准强调快速、跨端、可访问和有效链接。 | 让期待孩子的家庭感到温暖、从容，同时很快理解并使用工具。信息与证据可靠，下载和所有状态可用。 |
| FWA | 官方定位强调数字设计与开发的创新。Live Judging 公开说明采用评审平均分，最低 20 位评审投票、70 分门槛、当日最高者获 FOTD，项目最多进入评审 14 天。初始 50 分只是入场位置。没有查到与 Awwwards 同类的公开固定四项权重。 | 提供与主题紧密相关、能记住的原创体验。我们的内部检查只报告具体缺陷与验收结果，不把自评分称为 FWA 分数。 |

官方来源：[Awwwards 作品页中的公开评分项目](https://www.awwwards.com/sites/aesop-aromatique-candles)、[Awwwards 移动端指南](https://www.awwwards.com/mobile-excellence-guidelines.pdf)、[Webby 2026/2027 评审标准](https://www.webbyawards.com/judging-criteria/)、[Webby 评审流程](https://www.webbyawards.com/judging-process/)、[FWA About](https://thefwa.com/about/about-fwa)、[FWA Live Judging](https://thefwa.com/live-judging)。

FWA 页面依赖 JavaScript；本次核对了官方页面公开 HTML 内嵌的页面说明。其说明保留了 2016 年新系统的历史描述；正式报名时仍需再确认实时规则。

## 参考作品与可借鉴的方向

以下仅选取表达与服务品质作为参考；不复制构图、素材、文案或交互代码。借鉴建议是我们的设计判断，不是评委对本站的评价。

- **Aēsop — Aromatique Candles**：Awwwards SOTD，2021-01-28。官方说明强调原创插画与内容组成私密、个性化的体验，并收录插画动画与产品布局。适合借鉴“视觉世界和内容是一体”的做法：让月亮、时间与期待孩子的心情成为本站独有的表达，而不是给通用卡片加装饰。[官方获奖页](https://www.awwwards.com/sites/aesop-aromatique-candles)
- **Google Store**：2026 Webby Best User Interface 的 People's Voice Winner。适合把成熟消费产品的清晰交互作为功能参照：主操作稳定可见，选项易懂，结果有明确层级，移动端保持同等完整。[官方获奖列表](https://winners.webbyawards.com/winners/websites-and-mobile-sites/features-design/best-user-interface)
- **Sleep Well Creative**：2026 年 1 月入选 Rob Ford 的 **The Rob FWA** 个人策展奖，不能将此身份写成 FOTD。官方点评赞赏动画、声音与个人细节服务于助眠体验。适合借鉴“所有细节服务同一情绪”的完整性；本站可以使用轻柔的视觉节奏，但无需自动声音或强制动画。[官方策展页](https://thefwa.com/FWA25/RobFWA.html)

## 本项目的内部验收标准

保留奶油色、柔玫瑰色与粉蓝色的家庭气氛。工具保持静态轻量架构；生日、受孕日与结果留在浏览器。娱乐性质与证据链接始终容易找到。以下标准全部是项目内部约定，不是奖项官方分数门槛。

| 维度 | 可执行的验收要求 |
| --- | --- |
| 原创视觉概念 | 明确围绕“月历中的一份小小期待”展开；有原创、可识别的主视觉和品牌符号；缩小截图后仍能辨认布局主次。不能依赖重复的大圆角卡片、库存插图和装饰性渐变。 |
| 排版与秩序 | 标题、导语、正文、数字、注释有连续的层级；正文行长适合阅读；留白与栅格一致。桌面、平板、手机分别审查，不仅缩放桌面。 |
| 首屏任务 | 页面名称、两种日期模式、输入、主要按钮和娱乐边界易于发现；用户不用穿过长动画或介绍才能计算。输入日期的方法必须真实可用。 |
| 结果体验 | 清楚区分“传统猜测”和准确换算的农历信息；展示年龄、月份及计算依据；变化有克制的反馈。加载、空白、错误、有效、重算等状态完整。 |
| 交互细节 | 按钮、模式、导航、折叠问答、图表定位均提供一致的 hover、focus、active 状态。内容在动画失败或关闭时仍可读；尊重 prefers-reduced-motion。 |
| 无障碍 | 键盘能完成主流程，焦点可见；输入有真实标签、错误可感知、结果可播报；不只用粉蓝和玫瑰颜色传递意义。普通文字对比度至少 4.5:1，大文字至少 3:1。 |
| 内容与信任 | 民俗和医学证据分开；引用可核实研究；无“科学预测”“高准确率”暗示。导航、页面标题、元数据、说明与真实功能一致。 |
| 语言与受众 | 公开产品保持英文；验收包括中文Chrome中日期控件的真实显示。首页及主流程不出现设计思路、工程术语或内部评审口吻；方法和隐私页用访客能理解的文字解释必要信息。 |
| 全站完成度 | 所有公开页面共享同一设计体系，长表格局部滚动，下载格式与页数准确。PDF 和预览看起来属于同一品牌，打印仍清晰。404、页脚、菜单都应完成。 |
| 性能与稳定性 | 不为装饰引入重型库；首屏图尺寸明确、压缩合理、字体本地加载。检查页面移动端性能、CLS、控制台与请求；实验室值记录环境，不能当真实用户现场数据。 |
| 真实验收 | 实际浏览器检查 390px 手机、平板和桌面；填写日期、切换模式、计算、错误、重算、键盘、折叠问答、下载与跨页导航。截图审查至少两轮，修正明确缺陷后再复查。 |

完成一次验收只表示当前发布符合记录在案的内部标准。实际 Awwwards、Webby 或 FWA 结果仍需要正式报名和独立评审。后续以真实用户使用和 Search Console 数据继续迭代。
